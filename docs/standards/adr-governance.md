# ADR 治理规范

状态：Current
最后更新：2026-07-29
治理对象：ADR 准入、全局编号、元数据、状态、取代关系与归档路径
依据 ADR：`docs/adr/0015-standards-as-governance-source.md`、`docs/adr/0016-remove-document-templates.md`
关联测试：`tests/contract/test_adr_governance.py`

## 目的与边界

本标准规定哪些决定必须使用 ADR，以及 ADR 如何编号、流转、取代和登记。架构文档描述当前结构，
设计文档描述接口与验收，计划描述实施步骤，实验报告提供外部模型证据；ADR 只保存决定、理由和
长期后果，不重复这些正文。

## 强制规则

### 准入

改变系统边界、公开 API、持久化语义、事实来源、解析路由、跨服务契约与端口、高成本工程约束或
standards 的实质规则时必须新增 ADR。实现细节、操作步骤、实验原始结果和不改变语义的文档整理
不得单独建立 ADR。

### 登记时机

- 设计文档定稿（设计状态 Accepted）时评估是否触及准入情形，触及则同轮登记 ADR，避免决策
  滞后与事后补登。
- 修改被 ADR 覆盖的正文（架构/设计/标准/README 与 AGENTS 定位表述）前，先确认该处是否有
  ADR 覆盖；语义变更须新增 ADR（完整取代或正文关联），不得静默改写既有决定。

### 编号与路径

- 文件名固定为 `NNNN-lowercase-slug.md`，编号在整个仓库单调递增且进入主分支后永不复用。
- Proposed 和 Accepted 位于 `docs/adr/`；Rejected 和 Superseded 位于 `docs/history/adr/`。
  两处使用扁平目录，不按年份或产品版本分组。
- 新 ADR 使用当前最大编号加一，并在同一变更登记 `docs/adr/index.md`；并行分支冲突在合入前
  重新编号。
- `docs/adr/index.md` 是当前与历史 ADR 的唯一全局登记表。

### 元数据与状态

每份 ADR 在标题后依次声明 `状态`、`日期`、`领域`、`决策阶段`、`取代`、`被取代`。

- 状态只允许 `Proposed`、`Accepted`、`Rejected`、`Superseded`。
- 领域只允许 `解析与评测`、`数据与持久化`、`API 与任务`、`审阅与发布`、`工程治理`；新增领域
  须先经 ADR 扩展本清单。
- 决策阶段使用 `v<主版本>.<次版本>`，表示决定首次形成的阶段，不限制后续版本继续适用。
- 没有取代关系时写 `—`；存在关系时使用指向实际文件的 `ADR NNNN` Markdown 链接。

`Proposed` 可变为 Accepted 或 Rejected；Accepted 只能由后续 Accepted ADR 完整取代并变为
Superseded。完整取代必须在新旧 ADR 中双向登记；部分补充、范围收紧或实验恢复只写正文关联，
不改变旧 ADR 状态。

### 章节

每份 ADR 使用统一章节：`## 背景`、`## 决定`、`## 后果`、`## 关联`。`## 关联` 列出现有标准、
测试、设计与 ADR 链接，不复制其正文。

## 执行与门禁

1. 按本标准创建 Proposed ADR，分配下一编号并登记 ADR index。
2. 依次写入 `背景`、`决定`、`后果`、`关联`；依赖外部质量时先完成冻结实验。
3. 接受或拒绝后同步状态、索引、关联架构/设计与独立实施计划。
4. 完整取代时同步双向元数据并把旧 ADR 移入 `history/adr/`。
5. 运行 ADR 结构、Markdown 链接和代码映射测试；人工确认决定没有复制实现计划或实验原始数据。

## 变更与取代

Accepted ADR 正文不得静默改写。允许修复失效链接、补充反向取代元数据或增加明确勘误；任何新
决定必须新增 ADR。项目发生大的变动（架构/定位/服务形态变化）时，检查既有 Accepted ADR 是否
仍成立；失效决定以新增 ADR 取代，不得静默废弃。修改本标准的准入、编号、状态、取代或归档
规则时同样先新增 ADR；旧标准文本不单独归档，由对应 ADR 与 Git 历史解释。

## 审查与优化留痕

- 长期决策集中治理或项目大变动时修订既有 ADR：逐份核对决定是否仍成立、链接是否有效、正文
  是否与现状一致。
- 允许的正文修改仅限修复失效链接、补充反向取代元数据、明确勘误（措辞与状态注记过期）；
  勘误以 `（勘误：YYYY-MM-DD <说明>）` 形式在正文或关联节留痕，不改变决定语义。
- 语义变更（决定内容变化）必须新增 ADR 完整取代，不得以勘误形式改写既有决定。
- 新领域、新枚举等元数据清单变更须同步本文件的留痕注释与契约测试常量。
