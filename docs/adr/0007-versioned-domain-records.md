# ADR 0007：版本化领域记录与受保护重建

状态：Accepted
日期：2026-07-27

## 决定

解析运行、抽取运行、页面事实、知识候选和审阅事件使用追加式版本记录。再次解析或抽取不得删除
旧运行的数据；已发布快照保持不可变。

v0.3 使用 Alembic 增量迁移。允许个人开发环境重建 `af_` 数据，但只能通过独立命令执行：命令
先输出数据库、表、行数和备份清单，随后要求完整确认词。应用启动和普通 `upgrade` 不执行删除。

## 后果

查询必须显式选择最新成功版本。存储量会增加，但可审计性和后续学习引用的稳定性优先于节省少量
本地空间。重建命令不得接受运行库以外的模糊目标或跳过确认。
