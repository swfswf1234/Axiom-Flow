# ADR 0006：MySQL 持久任务与 API v1

状态：Accepted
日期：2026-07-27

## 决定

v0.3 使用 MySQL 任务表和独立 Python Worker 执行解析与知识抽取。API 改为 `/api/v1`，长命令
返回 `202` 和任务资源，Web 通过轮询查看进度。任务使用租约、心跳、有限重试、幂等键和协作式取消。

不引入 Redis/Celery；当前单用户吞吐不值得增加两个运行组件。也不使用 FastAPI 进程内后台
循环，因为开发重载、多进程和崩溃恢复会产生不明确的执行语义。

## 后果

本地运行需要 API 与 Worker 两个进程。HTTP 不再等待整篇文档完成，任务中断可恢复，后续批量
导入可复用同一队列。v0.2 无版本前缀接口由 v0.3 替代，不承诺兼容。
