# ADR 0008：不可变解析产物包与逐页检查点

状态：Accepted
日期：2026-07-28

## 决定

每个 `ParseRun` 的派生产物固定写入
`data/documents/<document-content-hash>/parse-runs/<parse-run-id>/`。运行目录包含逐页 Markdown、
规范化 JSON、页图、可定位的图表裁剪、脱敏供应商响应、整书 Markdown 和带 SHA-256 的最终清单。
原 PDF 继续位于内容哈希目录的 `source.pdf`。

页面事实和对应产物按页提交。Worker 重领同一任务时复用该任务的 `ParseRun`，只跳过数据库记录
和磁盘校验均通过的页面。运行完成前只写 partial 清单；全部页面和清单验证通过后才能把运行标为
`parsed`。预算耗尽、双解析器失败、非法响应和未声明空白的空正文均不得静默降级为成功。

数据库保存产物种类、相对路径、内容哈希、MIME、页码、块序号和 bbox 元数据。API 不返回本地
绝对路径，只按产物 ID 列出和下载产物。

## 后果

长教材在进程中断后不需要重做已验证页面，解析历史和文件可独立审计。存储量会增加，清理仍须
遵守已发布快照和原件不可删除的约束。旧的共享 `pages/` 目录不再作为新解析运行的产物契约。
