# ADR 0013：选择性历史保留与 Git 锚点

状态：Accepted
日期：2026-07-29
领域：工程治理
决策阶段：v0.3
取代：—
被取代：—

## 背景

`docs/history/` 当前同时保存被取代 ADR、全部关闭计划、旧操作指南和 v0.1 文档整树。ADR 需要
完整编号与取代链，真实迁移和数据清理记录需要长期审计；例行文档计划、失效命令和旧文档副本
则可由当前事实与 Git 历史恢复。全量归档会持续膨胀，并增加误用旧命令和旧架构的风险。

## 决定

History 只保存无法由更高优先级事实源替代的长期审计证据：

1. Rejected/Superseded ADR 永久保留，继续参与全局编号和取代关系校验。
2. 关闭计划只有在记录已执行的 D 类数据操作、迁移/发布里程碑、事故复盘或不可替代外部证据时
   才进入 `history/plans/<year-month>/`；其他计划在事实同步完成后删除。
3. 实验样本、结果和评分由 `evaluation/` 保存，采纳或拒绝结论由 ADR 保存，不复制实验计划。
4. 失效操作指南默认删除；旧版本操作只从对应 Git commit 或 tag 恢复。
5. 被整体替换的旧基线使用短摘要记录范围、失效原因和不可变 Git commit，正文与代码从该锚点
   恢复，不在当前树中复制。

计划关闭前必须写明 `Retain` 或 `Delete` 及理由。删除前搜索全部引用；没有有效 Git 锚点或仍含
唯一外部证据的资料不得删除。

## 后果

History 规模由审计价值而不是任务数量决定，旧命令不再出现在当前文档树。查阅完整旧基线需要
使用 Git，仓库迁移时必须保留 Git 历史。误删风险由引用搜索、固定锚点、结构测试和独立可回滚
提交控制；浅克隆或导出的源码包不能视为完整历史档案。
