# ADR 0001：本地优先与运行数据存储

状态：Superseded  
日期：2026-07-27
领域：数据与持久化
决策阶段：v0.2
取代：—
被取代：[ADR 0005](0005-mysql-runtime-storage.md)

## 决定

本 ADR 的 SQLite 存储选择已由 `ADR 0005` 取代。原始决定保留为 v0.2 早期设计的
追溯背景；当前运行事实源、迁移方式和测试隔离规则以 `ADR 0005` 为准。

## 后果

本地文件产物、Excel 显式发布和无需账号的目标仍有效，但不再规定 SQLite 为运行库。

## 替代方案

首期 PostgreSQL、Excel 直接双向同步和 Neo4j 均未采用：它们增加部署或事实冲突，但
未解决当前的解析质量与审阅问题。
