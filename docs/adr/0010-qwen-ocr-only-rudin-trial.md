# ADR 0010：Rudin 试跑采用 qwen-vl-ocr 单模型路线

状态：Accepted
日期：2026-07-28
领域：解析与评测
决策阶段：v0.3
取代：[ADR 0002](../history/adr/0002-parser-routing-and-provider-boundary.md)
被取代：—

## 决定

Rudin 扫描教材恢复为受控的 20 页链路试跑，只调用阿里百炼 `qwen-vl-ocr`，不再调用
`qwen-vl-plus`，并从当前实现中删除 MinerU 路由。试跑固定使用 PDF 物理页 20–39，每页最多
调用同一模型 3 次，任务总预算为 60 次；请求上限为 8192 tokens，单次超时为 180 秒。

供应商响应只有在 `finish_reason=stop`、顶层页面 JSON 完整且正文、内容块与页面类型通过校验时
才能形成页面事实。完整结束的响应允许用固定版本 `json-repair` 修复未转义换行等 JSON 语法，
修复标记必须进入供应商元数据，修复后仍执行同一页面 schema。截断、非法结构、空正文、限流、
超时和 5xx 可在页级重试；不得从截断响应中提取一个嵌套内容块并伪装为整页结果，也不得静默
切换模型。

真实单页诊断确认 `qwen-vl-ocr` 会返回只有非空 `markdown` 的完整顶层对象，而不遵循提示中的
`blocks/page_kind` 字段。供应商适配器接受这一 OCR 原生契约，保留原始响应，并按 Markdown 空行
确定性生成 heading、formula 或 paragraph 块，页面类型归一化为 `content`。该规则的契约版本为
`qwen-ocr-markdown-v2`，必须进入任务幂等版本、ParseRun 摘要和供应商元数据。v2 在结构化修复
前保护 JSON 字符串中的单反斜杠 LaTeX，避免 `\bar`、`\begin` 被解释为控制字符；只有嵌套块、
空正文或未完整结束的响应仍然拒绝。

解析任务显式绑定包含端点的页范围。局部运行必须在任务 payload、ParseRun 供应商摘要和最终
manifest 中声明范围，不得解释为 317 页整书解析完成。链路完成后固定抽检 PDF 第 20、24、29、
34、39 页；五页均无明显整段遗漏、阅读顺序错误或主要公式不可辨，才关闭本轮质量任务。

## 后果

本决定取代 ADR 0002 中当前视觉解析的双模型回退和 MinerU 对照路线，并允许在限定范围内恢复
ADR 0009 阻塞的工程链路。ADR 0009 的既有失败结论和报告仍作为历史证据保留；本次 20 页通过
不自动采纳 317 页整书路线，整书运行仍需单独决策。

成本不是本轮优化目标，但预算仍按实验治理要求冻结。失败运行保留逐页检查点和 partial manifest，
重试复用已校验页面，不覆盖旧 ParseRun。
