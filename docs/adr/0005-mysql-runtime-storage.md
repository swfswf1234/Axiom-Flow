# ADR 0005：MySQL 运行事实源与版本化迁移

状态：Accepted  
日期：2026-07-27
领域：数据与持久化
决策阶段：v0.2
取代：[ADR 0001](0001-local-first-and-storage.md)
被取代：—

## 决定

v0.2 使用现有 MySQL 实例的 `xqfm11` 作为运行元数据事实源。所有本项目表使用 `af_`
前缀，禁止读写 Legacy 或其他项目的同名表。PDF、页图和工作簿继续保存在本地 `data/`；
Excel 仍是人工编辑入口，不是运行查询库。

表结构只能通过 Alembic 显式迁移变更，应用启动只校验版本并恢复中断的本地任务，不执行
自动建表。集成测试专用 `axiom_flow_test` 数据库可由测试在不存在时创建，且测试库名不得
与运行库相同。

## 后果

运行状态、发布快照和未来学习服务可使用持久的 MySQL 事实源，同时通过表前缀与共享库
中的既有项目隔离。部署前必须执行 `alembic upgrade head`；缺失或落后的迁移版本会使
应用拒绝启动，避免静默运行在错误 schema 上。

## 替代方案

不再采用 SQLite，因为现有 MySQL 已可用且更适合长期保存工作台事实。未新建独立运行库，
因为 `af_` 前缀已足以避免碰撞；未来需要更强隔离时可迁移到专用 MySQL 数据库。
