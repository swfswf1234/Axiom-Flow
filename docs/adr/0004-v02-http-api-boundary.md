# ADR 0004：v0.2 HTTP API 与静态工作台边界

状态：Superseded
日期：2026-07-27
领域：API 与任务
决策阶段：v0.2
取代：—
被取代：[ADR 0006](0006-persistent-jobs-and-api-v1.md)

## 决定

本 ADR 记录 v0.2 的 HTTP 边界，已由 ADR 0006 的 API v1、持久任务和独立 Worker 取代。
下列内容只解释历史行为，不是当前兼容契约。

v0.2 以 `backend/app/main.py` 提供同源 HTTP API，所有业务接口使用 `/api` 前缀。
独立的 `web/` 原生静态前端只读取查询结果和提交导入、解析、审阅、工作簿、发布命令；
它不直接访问 MySQL、PDF 文件或百炼凭证。

文件上传先落入本地临时目录，再由领域服务以内容哈希归档；页图和工作簿只能由后端生成
文件响应。CORS 仅保留本机开发地址，默认部署使用同源访问。

## 后果

页面审阅、证据校验、发布版本和状态转换集中在后端，命令行、未来桌面端和聊天服务可复用
同一领域服务。前端不需要框架构建步骤，但复杂图谱交互升级时可在不改变 API 的前提下替换。

## 替代方案

没有采用旧 `app/` 的 API 扩展，因为其 PostgreSQL/MinerU 契约为 Legacy；也没有将 MySQL
连接直接暴露给浏览器，因为这会绕过审阅与发布约束。
