# ADR 0009：拒绝当前 Rudin 扫描教材解析路线

状态：Accepted
日期：2026-07-28

## 决定

不采用当前 `qwen-vl-ocr` 主模型与 `qwen-vl-plus` 回退模型的页级路线解析 317 页 Rudin 扫描
教材，也不启动最多 634 次的整书调用。MinerU 3.4.4 隔离安装未成功，因此本轮没有可采纳的本地
候选。

本决定依据 `evaluation/manifests/rudin-scan-v1.json`、
`evaluation/reports/rudin-scan-v1-scorecard.json` 和评测报告。百炼候选平均分为 0.604，9 页只
返回单个局部块，2 页返回截断且无 bbox 的 Markdown，存在公式、来源证据和完整性关键失败。

## 后果

整书解析保持阻塞，不产生 `parsed` 运行，不将局部模型结果写入正式页面事实。已实现的不可变
产物、断点续跑、预算和失败门禁保留，供下一候选复用。

恢复条件是：成功安装并验证一个本地扫描数学解析器，或引入能稳定返回完整页面结构的新供应商；
新候选必须先复用同一 12 页 manifest 并达到既定评分门槛，之后另立采纳 ADR。

## 后续决定

ADR 0010 接受修复响应完整性、增加输出上限后的 `qwen-vl-ocr` 单模型路线进行 PDF 第 20–39 页
链路试跑。本文对旧提示与旧响应处理所得结果的拒绝结论仍然有效，但不再阻塞该限定范围试跑。
