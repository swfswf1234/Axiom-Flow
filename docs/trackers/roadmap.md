# 能力路线图

[completed](completed.md)；关联任务 ID 必须存在于其中一张台账。

```mermaid
flowchart LR
    M0[M0 工程治理] --> M1[M1 解析质量]
    M1 --> M2[M2 审阅工作台]
    M2 --> M3[M3 知识发布]
    M0 --> M4[M4 工程可靠性]
    M3 --> M4
    M3 --> M5[M5 检索契约]
    M4 --> M5
    M5 --> M6[M6 学习交互]
```
