## 当时的测试说明

每个计划必须在实施前明确验证命令、验收样本和关闭门槛。评测用于决定模型或方案是否值得采纳；
测试用于保护已采纳实现，二者不能相互替代。

当时记录的最低测试层次包括单元测试、集成测试、样本回归、任务测试和 API 协议测试。MySQL
集成测试使用独立测试库并在测试前后清空 `af_` 表；测试库与运行库相同会立即失败。

文档与受管代码使用代码映射测试；架构变化追加架构语义和依赖方向测试；设计契约变化追加设计
语义测试。共享模型、状态机、路由或跨领域流程还需要回归与端到端验证。可复现失败进入回归待办，
外部模型质量失败保留在评测报告中。

此处不保留可复制执行的旧命令，避免历史文档成为当前操作入口。
