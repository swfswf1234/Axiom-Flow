# 首轮解析路由评测

状态：Superseded
最后更新：2026-07-28

## 目标

用固定的真实 12 页样本比较本地文字层、百炼视觉模型和可选 MinerU 对照，给出后续选择性
解析路由是否达到采纳门槛的证据；本计划不修改已接受的 v0.2 生产供应商边界。

## 替代计划

原计划假设首轮必须同时覆盖四类页面。2026-07-28 收到的数学分析数据集全部为扫描 PDF，不能
诚实提供电子数学文字类别。本计划由 `2026-07-v03-rudin-scan-ingestion.md` 替代：先用单一
`scanned_math_textbook` 类别验证实际首本教材，后续类别到达后另建增量实验。

## 历史阻塞

当前仅有计算机论文的单页连通性预检，尚未提供覆盖数学文字、扫描数学、公式密集及
表格/图示四类页面的样本。因此正式质量实验暂停，不把预检结果视为质量结论。收到样本后
先冻结匿名 manifest，再从第一个未完成工作项继续执行。

## 工作项

- [x] 使用当前计算机论文第 1 页执行连通性预检。首次主模型响应含尾随内容而回退成功；
  修复 JSON 对象提取后，主模型 `qwen-vl-ocr` 成功，详见 `evaluation/reports/parser-v1-preflight.json`。
- [ ] 从获准的数学 PDF 选择四类页面各 3 页，填写未提交的 `evaluation/manifests/parser-v1.json`。
- [ ] 记录每页来源产物标识、预期评分维度和页号，不提交 PDF、页图或绝对路径。
- [ ] 在最多 36 次百炼调用内运行候选解析器，并保存无凭证的结果 JSON。
- [ ] 人工填写逐页评分、理由、严重错误、运行标识、模型配置摘要、耗时和费用估算。
- [ ] 使用 `python -m evaluation.scorecard` 输出评分卡并撰写评测报告。
- [ ] 达标时新增选择性解析路由采纳 ADR；未达标时将失败原因回写到 `Proposed` 设计并创建下一轮实验。

## 验收

manifest 通过校验且覆盖四类页面各 3 页；结果不超过 36 次调用并不含凭证；评分卡明确
`accepted` 为真或假；所有可复现失败都登记到回归待办。仅 `accepted: true` 不足以修改
选择性路由，仍需要 ADR 接受。

## 预检记录

初次报告 `parser-v1-preflight-initial.json` 保留了适配器发现的尾随内容诊断，未包含模型正文
或凭证。适配器修复后的正式预检仅使用主模型 1 次调用即返回合法 JSON；该结果只证明链路
可用，仍需数学样本完成正式 12 页质量评测。
