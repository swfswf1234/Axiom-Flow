## 收口结论（2026-11-25）

**原整本真机窗口不再执行，本案以“取消窗口＋证据与欠账分派”关闭，不以跑完 W6／W8 关闭。** 需求方裁决＝
主链已经实现并分开验收，真机窗口不再是主链关闭的前置；逐书、分阶段与配套习题真机读数由 PLAN-037、
PLAN-045 及 PLAN-028 的分项验收承担，不再为一个聚合窗口重复占用模型服务与制造数据写入。本结论
不把分项读数冒充 b05 整本 W6／W8：两轮均**未执行**，其窗口专属指纹、全本调用成本与整本两侧对账也不再生。

- **W4／W5＝不适用**：没有窗口发令，因而不取窗口前三面指纹或执行窗口备份；两项规程仍可供未来另行批准的
  D 类操作复用，但没有本轮执行事实。
- **W6／W7／W8／W9＝未执行且不再执行**：W7 的人工改名／重排取证、W8 的整本内容轮与 W9 的可选 `full`
  对照轮均随窗口取消。既有分项验收不覆盖的现场问题转常规缺陷或后续样本验收，不继承“整本已通过”的结论。
- **R7＝主体已落地、关闭时尾项移交 [PLAN-026](2026-10-26-annotation-replay-and-kp-text-engine.md)**：三键已进
  `model-integration.md`，槽位默认 `qed-gateway`，空名与闭集外名在 `resolve_text_engine_name` 抛
  `TextSlotError` 并由 API 映射 503。本案关闭时 `.env.example` 尚未列三键，且 `load_settings` 会跳过空环境值／
  `.env` 空值，故两件在 PLAN-026 的 R7 移交节登记，未在本轮改码。**后续交付**＝PLAN-026 已于 2026-11-25
  实现三键显式空优先并停用、503 零写入与配置／工厂／API 守护，原移交尾项了结。
- **R11 已了结**：后续批文落地为 `KA-5`／`KA-33` 的目录页条目腿，模型判页与逐页整理由 W14~W18 交付，
  不再以本案 W3 为前置。
- **R17 随最终门禁了结**：本轮收口全量门禁作为重复定位记录，读数写入下方「验证与验收」；门禁未绿前不宣称关闭完成，历史单点漂移不单独阻塞关闭。
- **R12~R16 不再走原窗口取证**：R12 的 `full` 容错计数留 PLAN-026 常规缺陷；R13 的 `chapter` 账键按现行
  `KA-23` 的实测／守护口径核查；R14／R15 属屏侧改名与挂靠交互，随根侧界面批处置；R16 的家具分母与偏移
  投票不再做整本标定，若后续真书出现分叉，按具体样本另立缺陷。五项均不得解释为“已验证通过”。
