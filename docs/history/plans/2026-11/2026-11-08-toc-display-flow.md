## 目标与成功标准

**目标**：在**未经过人工二次整理**的真实教材目录上，把「判页 → 整理 → 检索确认 → 两层成行 → 页段读出」
走成一条可复算的链。本壳先交口径（W1），**用户确认前不动代码**；W2 起按确认后的裁决实施。
**本壳零真实模型调用**：所有模型腿用确定性替身，真实窗口仍归 PLAN-027。

1. **S1 判页**：含「目录」标记的页在前 10 页内时，从该页起逐页整页判到第一张非目录页；标记不在前
   10 页时向后递推；标记全无时退确定性条目腿。每页的判定与条目都出自同一次整页读数。
2. **S2 整理**：条目名不含行末引导点与印刷页码；`……`、纯页码行、目录书眉、页眉页脚都不成为行。
3. **S3 检索确认**：每条有印刷页码的行都在正文里回定位成功；不中的行交核对腿；核对仍不中的按
   未定位披露（不编造页号）。无印刷页码的行也进核对腿，候选面由其上下已定锚行夹出。
4. **S4 两层**：章／知识点两层成行，第三层不成行（`KA-6` 不变；`KA-62`：`§` 节下的纯编号细目折入
   所属二级的显示段，不占节点、枚数进批次流水）；知识点行仍是叶子。
5. **S5 页段**：任意两行的显示段**不相交**；显示段按页序排列；章段止于首个知识点之前（同页时
   章只占这一页）；知识点段＝自身锚页到下一知识点之前，末枚到章末；知识点段互不重合。
6. **S6 其他行**：书前件单页、书尾附件区连续、章末习题段到章末；它们同样不与任何行重合。
7. **S7 去重**：同一父下同名（`norm_key`）只出一行；六类书级附件名全书只出一行；跨章同名保留；
   「一个前言出两行」不再发生；被折叠的行数在批次流水可见。
8. **S8 三面一致**：工作区、确认回显、导出面用同一份投影读出同一组页段。

## 范围与非目标

**范围**＝判页腿的兜底读数、两条整理腿的脏行边界、检索确认腿的覆盖面、成行去重、读面显示段派生，
以及 `api.md`／`knowledge-analysis.md` 的同步；零 DDL、零真实模型调用。

**非目标**＝① 不改 `KA-6` 的两层上限与 `af_kp` 列语义；② 不改解析产物、`blocks.json` 与页行状态；
③ 不重跑任何解析或梳理批次；④ 不实现 8903 界面与 8900 提升作业；⑤ 不在本壳内做真实书验证
（归 PLAN-027 窗口与用户发令）；⑥ 不改点腿的取证区间（`section_spans_of` 的模型输入口径保持）。

## 目标流程（用户口径 → 链路）

1. **找到目录、拿到章列与页数**：按用户口径逐页判定（P-1~P-5）→ 整理腿出条目（名字、层级、印刷
   页码）→ 检索确认把每条钉到正文页。**「页数」不由目录里的印刷页码给，而由下面的页段规则从锚页推出**。
2. **LLM 梳理只做抄行与判层**：避免 `.....`、页眉页脚等脏读数。清洗与剔除留在确定性一侧：行末引导点
   与印刷页码剔离、整行家具剔除、目录书眉与纯数字行跳过；模型不负责补结构、不负责编页码。
3. **检索确认，LLM 兜底**：每条行在正文里按「去空白前缀」检索，命中即定锚；不中走公式壳折叠；
   仍不中交核对腿（模型只在候选行里挑页，不许给候选外的页号）。**核对腿从「坏行」扩到「一切
   未确证行」**，包括无印刷页码的行。
4. **两层结构 ＋ 页段显示**：章与知识点两层；页段规则见下节，保证不重合、按页序、不重复。

## 判页与整理链路（用户确认口径）

| 编号 | 规则（结论 ＋ 判据） | 说明 |
| --- | --- | --- |
| P-1 | **起点候选＝前 10 页中整行命中「目录」或 `Contents` 的页**；前 10 页没有候选时按页序向后递推到全书（确定性文本扫描，零模型调用） | 标记判据与目录书眉闭集同源（`is_toc_marker_line`）；正文句子里的「目录」不算，只认独立行 |
| P-2 | **候选逐页整页判定**：整页全部非空块（带块类型、**不截断**）交判页腿，问「这一页是不是书的目录页」，从前往后逐页判 | 不再每页截到 400 字、不再一次问全书页集 |
| P-3 | **判为目录页即从该页起连续整理**：同一次读数按行格式返回条目（名字、层级、印刷页码）；下一页继续整页判定并整理，**直到第一张判为非目录页的页为止**，该页不接条目 | 目录页的右边界由逐页判定给出，不靠事后区间扩展 |
| P-4 | **候选被判非目录页**：顺延到下一候选；候选耗尽仍无目录起点：退确定性条目腿（全本扫描），并在批次流水披露「未命中标记／未判为目录」 | 现有三条回落保留，目录零行仍不发生 |
| P-5 | **模型不可用或单页失败**：该页退确定性条目腿，后续页仍继续判定与整理；失败页计数进流水 | 单页故障只坏那一页，不中断整段目录 |

## 页段显示规则（待确认口径）

页面切片与模型读哪几页是**两件事**：取证区间（服务端内部、决定点腿读哪些页）不改；显示区间
（API 的 `page_start`／`page_end`、UI 据此切片）按下面的确定性规则读时派生，零新列。

| 编号 | 规则（结论 ＋ 判据） | 说明／例子 |
| --- | --- | --- |
| D-1 | **两类区间分离**：取证区间仍按 `KA-42` 的树序算式（章含自己的知识点页，点腿要读）；`page_start`／`page_end` 改为**显示段**，由本节算式派生 | 只改读面语义与算式，不改 `section_spans_of` 的点腿输入 |
| D-2 | **参与行**：`gen_status='candidate'` 的目录行与点行（`draft` 在飞、`rejected` 被本批取代，均不参与——沿用现有读面判据）；目录页自身不成行、不切片；锚点缺页的行不给显示段（`null`）并披露 | 与 PLAN-029 的 `stage` 五键同一统计域口径 |
| D-3 | **展示序**：从顶级行起按锚页升序、锚页相同按 `order_hint`，先出父再出子（DFS）；父子关系只由 `parent_id` 表达，排序不改树 | 保证父行永远排在子行之前，书前件在章之前、书尾附件在最后 |
| D-4 | **章段**：起点＝章锚页；终点＝**第一个子行（目录阶段即第一个知识点）的锚页 − 1**；无子行时终点＝下一章锚页 − 1，无下一章到书末；终点小于起点时取起点（**同页只展示这一页**） | 章锚 p9、首点 p15 ⇒ 章 `[9,14]`；章锚 p9、首点 p9 ⇒ 章 `[9,9]` |
| D-5 | **知识点段**：起点＝自身锚页（上一段已占该页时顺延到上一段末页＋1，并在读数披露「顺延」）；终点＝下一知识点锚页 − 1，封顶本章末；末枚知识点到本章末；**段与段不重合、按页序** | 点 p10、p20、p31（章末 p40）⇒ `[10,19]`、`[20,30]`、`[31,40]` |
| D-6 | **同页多枚知识点**：先到者拥有该页（D-4 的「只展示第一页」推广），后到者从下一页起算；顺延越过本章末时该行显示段为空并披露，不编造页 | 两点同锚 p20 ⇒ 前 `[20,20]`、后 `[21,…]`；若章末也是 p20 ⇒ 后者空段 |
| D-7 | **其他行**：书前件（锚页早于第一枚知识点行）＝单页；书尾附件（锚页晚于最后一枚知识点行）＝自身页到下一行／书末；章末习题段＝自身页到本章末 | 习题段沿用 `KA-46` 的区间事实，但这里只用于显示，不改取证面 |
| D-8 | **更深一层**：点行（`node_kind='point'`）存在时按同一算式递归——有子的行止于首子之前，叶子行到下一个同级行的起点前 | 目录阶段只有两层，本规则在内容阶段自然生效，不新增层 |
| D-9 | **书末缺失**：`af_books.page_count` 为空时不给尾行终点（`null`），不猜书末 | 现状 `_kp_page_spans` 已按此退化 |
| D-10 | **三面一致**：工作区、确认回显、导出面共用 `_kp_node_out` 同一投影，显示段三处一致 | 与 `KA-15` 的导出面同一份行投影 |

| 编号 | 规则 | 说明 |
