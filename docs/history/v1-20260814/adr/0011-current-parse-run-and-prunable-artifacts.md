# ADR 0011：显式当前解析运行与可清理产物

状态：Accepted
日期：2026-07-28
领域：数据与持久化
决策阶段：v0.3
取代：—
被取代：—

## 背景

同一文档可以产生多个局部或完整解析运行。按创建时间隐式读取“最新成功运行”会让一次新试跑
覆盖正在审阅的结果，也会让页面图在每个运行目录中重复保存。完整保留所有历史文件又会快速放大
本地存储，并使 Web 难以区分当前结果、候选结果和已清理历史。

## 决定

`af_documents.current_parse_run_id` 是当前解析结果的唯一指针。新运行成功后仅成为候选，不自动
切换。显式切换只接受同一文档、状态为 `parsed`、产物状态为 `available` 且最终 manifest 校验
通过的运行；每次切换追加写入选择历史。现有数据迁移时回填每个文档最新的成功运行。

PDF 物理页图按文档和渲染契约共享，固定保存在
`data/documents/<hash>/page-assets/render-200dpi-v1/page-xxxx.png`，数据库登记为 `run_id=NULL`。
新运行的 manifest v2 分别列出运行私有文件和共享资产；校验器继续支持既有 manifest v1，且不
改写已经完成的不可变清单。

解析运行增加 `artifact_state=available|pruned`、`prune_summary_json` 和 `pruned_at`。清理保留
ParseRun、Job 与选择历史，只删除旧运行的页面、块、来源、质量和运行私有产物索引。执行必须：

1. 默认 dry-run，并核对文档 SHA-256 与保留运行 ID。
2. 拒绝当前、活动、已有审阅、被抽取或发布链路引用以及目录越界的运行。
3. 先把目录移动到 `data/trash/<operation-id>/`，写入墓碑摘要并验证当前运行。
4. 只有显式 purge 才删除 trash；阶段失败时可把目录移回原位。

## 后果

页面审阅和后续抽取获得稳定事实来源，新试跑不会改变当前结果。历史运行仍可查看模型、范围、
调用量、大小、manifest 和审阅摘要，但已清理运行不能读取页面或下载文件。共享页图降低后续运行
的重复存储；旧 v1 运行仍按原清单校验，直到被受保护工具清理。

## 回滚

代码可回滚到迁移前版本；迁移降级前必须确认没有依赖当前指针的调用方。尚未 purge 的目录从
trash 恢复并回写页面索引；已经 purge 的运行只能从执行前备份恢复。原 PDF 和当前运行不得进入
清理目标。
