# ADR 0002：分层解析路由与供应商适配边界

状态：Superseded
日期：2026-07-27
领域：解析与评测
决策阶段：v0.2
取代：—
被取代：[ADR 0010](../../adr/0010-qwen-ocr-only-rudin-trial.md)

## 决定

v0.2 的电子论文页以百炼视觉模型为主解析器：先调用 `qwen-vl-ocr`，失败时调用
`qwen-vl-plus`。PyMuPDF 同时提取文字层和块坐标，作为最低成本的页级事实、证据定位
依据及外部模型不可用时的可审阅降级结果。MinerU 保留为可插拔解析器和质量对照，
而非唯一主链路。

所有实现必须通过 `ParserAdapter`、`VisionProvider` 或 `TextModelProvider` 返回统一的页、
内容块、证据和质量数据。凭证只由本地 `.env` 提供，禁止进入日志或文档。

## 后果

视觉解析保证了 v0.2 对公式、图表和版面的统一入口，但每页都会消耗模型调用预算。后续
只有在固定实验表明低风险页面可安全文字层直通后，才引入选择性路由。替换模型不会改变
领域数据接口，但必须补充统一输出与质量回归测试。

## 后续决定

2026-07-28 起，当前解析路线由 ADR 0010 取代：Rudin 受控试跑只使用 `qwen-vl-ocr`，不再保留
视觉回退模型或 MinerU 当前实现。本 ADR 仅解释 v0.2 历史路线。
