## 目标与成功标准

**目标（V1.0 形态）**：产物从「解析出来」升级为「大模型易消费」：

```
PDF → 解析管线（MinerU，已有）
  → blocks 语义分诊（版式块过滤 + 公式/表/图/代码保留 + 未知类型审计 ledger）
  → 知识单元（块级切分为主体：数学感知边界，公式不腰斩；块序号锚点）
```

自 2026-11-02 起，原图后续两段「向量化（索引版本行增量）」与「检索服务（向量 + BM25 + RRF +
rerank，命中返回书/页/块三级溯源）」**移出本轮**，属 roadmap 检索线立项后的形态，与本壳的
关闭条件解耦（用户裁决；索引版本行的**承载位**已由 PLAN-024 裁决建列，见 R1 行）。

**成功标准**：

1. P1~P3（解析面，ARCH-022）与 R1（知识库面，ARCH-023 唯一待做条目）逐条实施，各带契约/单元测试；
   R2/R4 经 2026-11-02 取证判已达成、R3 移出本轮（逐条状态见工作项表）；
2. 换模型/换参数不引发全量重解析（P1 内容寻址可证；R1 索引版本行随检索线立项才产生写入需求，
   其列与 `op_kind='index'` 预留位已建、守护断言计数恒 0）；
3. 崩溃/半写不产生假就绪版本目录（P2 原「manifest-last」口径已被 PLAN-019 裁决 ② 推翻，现判据＝DB 单源 + 提交序，见 PLAN-019 S3/W5 与 ADR 0015）；
4. 【2026-11-02 移出本轮】原「检索端点经根仓库探索验证界面（v0 切分校验 → v1 BM25 → v2 向量混合
   召回）联调验收」：检索联调随 roadmap 检索线立项轮自设判据；其中「命中可回溯到页/块级原文」
   一项已由 R2 的 `Chunk.block_refs` 达成并常驻回归，不随本条移出而失去证据。

## 范围与非目标

**范围**：解析产物质量与结构（重跑判定、就绪标记、语义分诊 ledger）+ 知识库面的**切分与块级
知识单元**（R2/R4，经取证判已达成）与**索引版本行的表内承载位**（R1 的建列部分已由 PLAN-024
裁决⑯ 落地，写入者未建）。

**非目标**：渲染与前端消费界面（根仓库 8903 前端的事，本仓库只保证契约与产物）；
**检索与向量化本体**（R3 的混合检索配方与 8902 检索端点、R1 的索引行写入者）——自 2026-11-02
用户裁决移出 v1.0 本轮，归 [roadmap.md](../trackers/roadmap.md)「分块与向量检索」条与长期行
`ARCH-012` 的立项前调研与去留裁决；`api.md`「未开放面」段的 `GET /api/v1/search` 预留口径不变，
本壳不为其设关闭门。**知识图谱暂不做**（2026-09-22 用户裁决，roadmap 预留，RAG 成熟后再裁）；多解析引擎
bridge（P4 暂缓）；查询改写（P 系外 R5 后置，问答面归根仓库学习中心）；纯文件无 DB
存储与 GraphRAG 拍平（R6 拒绝，判据见工作项表）。
