## 目标与成功标准

1. 每本书的整册工作区回包带一枚 `stage` 对象，五键齐备且为读时派生：`rows`、`endorsed_rows`、
   `blank_summaries`、`unlocated_rows`、`done`。既有键（`nodes`、`in_flight_batch`、`review_flags`）
   读数与形状逐字不变。
2. `done` 严格等于三条件合取：统计域内每一行 `summary` 非空、每一行 `confirmed=1`、未定位零枚；
   统计域零行时恒 `false`。任一条件不成立即 `false`，不得用「总结齐」「确认齐」单独代替。
3. 零 DDL、零新端点、零写库：不新增表列、不改迁移链、不写任何行；派生在同一次请求内完成，
   不引入逐行查询。
4. 未定位的判据与 `KA-33`／`KA-41` 的披露同义：锚点仍全部停在本书目录页的行计为未定位；
   锚点为空的**人工直填行**不在此列（它不是「条目没找到页」，而是「没有条目光凭」）。

## 范围与非目标

**范围**：

- `schemas.KpWorkspaceOut` 加可选 `stage` 与对应模型；`get_kp_workspace` 在既有 `nodes` 之后派生并返回。
- 一枚判据纯函数（统计域、三条件、四键计数），与 `node_type` 的派生共用同一份活行读数。
- `tests/contract/test_api_v1_contract.py` 的键闭集与四例断言；`tests/unit/test_knowledge_pipeline.py`
  的纯函数四例（零行／有行未确认／确认齐但存在未定位／三条件齐）。

**统计域（写死，避免日后漂移）**：该书 `af_kp` 中以 `gen_status='candidate'` 在册的活行，且
读时派生 `node_type` ∈ {`chapter`, `point`} 的行；`rejected` 行与在飞 `draft` 行不计，
`exercise` 与 `other` 两类附件行不计（它们按 `KA-39`／`KA-43` 不产出总结，若计入则任何带附件或
章末习题的书永不完成）。`rows` 即该域枚数；`blank_summaries` 数其中 `summary` 为空串者；
`endorsed_rows` 数其中 `confirmed=1` 者；`unlocated_rows` 数其中锚点全部落在本书目录页集合内者
（锚为空的行不计）。`done` ＝ `rows > 0 ∧ endorsed_rows == rows ∧ blank_summaries == 0 ∧
unlocated_rows == 0`。

**未定位的读数来源**：按 `KA-27`「流水只答发生过什么、禁作当前态判据」，**不**以批次流水
`unlocated_outline_entries` 的名字清单直接计数（人工事后把锚点改回正文页的行会永远被旧清单误判）。
可行素材是当前行自身的锚点与本书目录页集合：目录页判据与 `KA-33` 同一把（确定性条目腿），
实现取整本复算或只对这批行的锚点页复算，由本仓按开销定；口径只要求「与 `KA-33` 的页级复核同义」。

**非目标**：

- 不新增表列、不改迁移链；`af_books` 的两枚真列（种类与梳理结局）与书目列表三段读数是
  PLAN-028／ARCH-036 的**批次结局**语义，与本案不是同一维：本案判的是「人已逐行确认的当前态」，
  既不消费该列也不阻止其落地；两案若同批实施，`stage` 仍须**读时派生**，不得改成读结局列。
- 不改 `_endorsement_missing`（`KA-14`）：确认门放行空总结是既有判据，本案只把「空总结」计进
  `blank_summaries`，不改门的宽窄。
- 不改批次流水 `result` 的键闭集、不改 `KP_RESULT_KEYS`。
- 不做课程级或跨书聚合、不改根侧前端（都归根仓库）。
- 不新设端点；不加「列批次」读面（本案不需要批次号）。
