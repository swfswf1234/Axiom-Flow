## 目标与成功标准

**目标**：把章腿从「只读章前正文＋子点总结、按全书位置收尾」改成一条**章级检索增强**的生成链：先用
本章标题与子点清单确定性地取一组专业定义（中文维基优先，无条目再退其他可信源），再让模型写
「本章学习内容」与「本章导读」；同时把点总结的定位从「压缩本节」改判为「提取本点的核心要点与
关键定义」。输出不再出现全书结构、页数与知识点数，也不再替读者安排后续章节。

1. **S1 章总结**：一段专业、精炼、准确的本章概览，起于本章对象与问题，沿定义／定理／构造给出
   结论链；不出现页数、知识点数、「本章位于全书…」「为第 X 章…」「本书／全书／这门课」等全书结构句。
   覆盖本章主要知识点为尽力目标，不为凑全覆盖而改写语义。
2. **S2 导读**：只谈本章的三段导读（总问题与难点 → 各点如何推进 → 学完本章能做什么）；
   不使用全书结构，不写后续章节的用途；第一轮允许较详细。
3. **S3 点总结**：`section_summary` 是「本点核心要点与关键定义的梳理」，不是原文压缩；与
   `key_definitions` 分工——前者串要点，后者给规范定义；不写章节位置，不复述推导。
4. **S4 检索**：章腿输入新增一块「检索资料」；查询词由本章标题与子点清单确定性派生，至多 8 条；
   中文维基优先，无条目再退英文维基与数学专业源；只取摘要、限长、去重；检索失败或无条目不影响生成。
5. **S5 模型档位**：章腿只用 8900 当前生效的文字槽位，本仓不切换共享槽位、不下发模型名、不调用
   其他模型；探测只用于把当前模型名记进校验注记，探测失败不影响生成。
6. **S6 校验与重试**：确定性校验挡全书结构句、页数与「定理／定义名无出处」；不过则同一模型附修改
   要求重试一次；仍不过则照写，并在章行 `meta.chapter_check` 记 `{passed, issues, model}`。目标是不进入
   这一环节。
7. **S7 质量窗口**：以 b05 第 3 章（p49–80，14 个知识点＋习题）为冻结样本重生成总结与导读，
   由用户按 S1／S2 评估；结论经用户确认后才把提示词与检索口径晋升设计。
8. **S8 回归**：`full`／`outline`／`exercise` 三值与点腿调用数逐字不变；检索只发生在章腿；零新阶段、
   零新端点、零 DDL。

## 范围与非目标

确定性校验与同模型重试链、b05 第 3 章质量窗口，以及 `KA-43`／`KA-45` 与新条文的同步。

## 已裁口径（2026-11-09 用户确认）

| 项 | 裁决 |

## 内容契约（拟晋升，待质量窗口确认）

| 编号 | 规则 |
| --- | --- |
| C-1 | **章总结＝本章概览，不是全书定位**：起笔给本章要学的对象与要解决的问题；中段沿定义→定理／构造→结论给结论链，条件与结论点具体名称；术语第一次出现给一句白话解释。不写页数、知识点数、全书结构、后续章节用途。专业、精炼、准确；不用「首先／其次／最后」拼凑。 |
| C-2 | **导读＝只带读者走本章**：三段——① 本章总问题与它难在哪；② 各知识点怎样一层层推进（上一步留下什么、下一步要做什么）；③ 学完本章能做什么（本章能力，不写后面哪一章会用）。允许较详细，但不复述节总结、不写全书结构。 |
| C-3 | **点总结＝要点与定义的梳理**：先给本点对象／问题，再给核心结论与成立条件，最后给关键定义、记号或公式；不复述推导过程、不写本章位置、不做原文压缩。`key_definitions` 仍只收术语的规范定义，两者不互相顶替。 |
| C-4 | **章级检索**：查询词＝章标题＋子点名称（必要时补点总结里的关键术语），去重后 ≤ 8 条；优先级＝中文维基 → 英文维基 → 数学专业源；每条只取摘要首段、≤ 400 字，合计 ≤ 3,000 字；进程内缓存，不落库不落盘；失败／无条目＝空，不阻断生成。检索只校准术语与定义，教材结论优先。 |
| C-5 | **只用当前槽位、不调用其他模型**：章腿请求体不带 `model`，模型由 8900 当前生效的文字槽位决定；本仓不切换槽位、不逐调用点名模型。可选只读探测（`GET /config/models`）只为把当前模型名记进 `meta.chapter_check.model`，探测失败时该键留空，生成照跑。校验不过时以**同一模型**附修改要求重试一次；两次不过则照写并落注记。 |
| C-6 | **确定性校验**：两段非空且形状可解析；禁页数（`共 N 页`／`p49–80` 一类页区间）、禁全书结构词（`全书`／`本书`／`这门课`／`本章位于`）、禁后续章节承接句；输出中带「定理／定义／准则／公式／判别法／检验法／法则」的名称须在材料或检索资料中出现。覆盖率不作失败条件。 |
| C-7 | **注明面＝章行 `meta.chapter_check`**：仅在「重试后仍不过」时写 `{passed, issues, model}`（`passed=false`；`issues` 为命中项短句数组；`model` 为探测到的当前模型名，未知写空串）。通过时不写这一键。不新增 `result` 键（`KP_RESULT_KEYS` 仍 42），不扩批次账本。 |

## 目标流程

1. **点腿先改角度**：正文材料 → 该点核心要点＋关键定义（`section_summary`）＋`must_master`／
   `key_definitions`；不写章节位置。
2. **章腿前取检索包**：章标题＋子点清单 → 查询词 → 中文维基优先 → 英文维基／数学专业源兜底 →
   摘要限长去重 → 章材料第四块。
3. **章腿一次生成**：章前正文＋子点总结＋检索资料 → 总结＋导读；提示词按 C-1／C-2。
4. **校验与重试**：确定性校验 → 不过则同一模型附修改要求重试一次 → 仍不过则照写并把
   `{passed: false, issues, model}` 记进章行 `meta.chapter_check`。
5. **质量窗口**：b05 第 3 章重生成，交用户评估；通过后才晋升设计。
